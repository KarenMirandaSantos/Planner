# 🌿 FocusFlow

O **FocusFlow** é um planner desenvolvido para auxiliar na organização de tarefas e produtividade no dia a dia. O sistema permite adicionar, concluir e remover tarefas de forma simples e intuitiva, utilizando uma interface moderna inspirada em aplicações reais de produtividade.

---

## 🚀 Objetivo do Projeto

Este projeto faz parte dos meus estudos em **desenvolvimento front-end**, onde estou praticando conceitos fundamentais de:

* HTML5
* CSS3
* JavaScript
* Manipulação do DOM
* Eventos
* Estruturação de layouts
* Interatividade com o usuário

Além de desenvolver minhas habilidades técnicas, o objetivo do FocusFlow é construir um projeto funcional, visualmente agradável e evolutivo para meu portfólio.

---

## ✨ Funcionalidades

* ✅ Adicionar tarefas
* ✅ Marcar tarefas como concluídas
* ✅ Remover tarefas
* ✅ Interface moderna e minimalista
* ✅ Layout organizado e responsivo

---

## 🛠️ Tecnologias Utilizadas

* HTML

* JavaScript
